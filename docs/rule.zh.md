名称：dsh-pet-StatusLight
功能：为deepseek harness配备的状态灯，显示所有界面之上，模型思考（运行）、发生错误、完成回答时切换动作并用聊天框提示。
设定：同文件夹下子文件夹均为可选角色（默认为红绿灯），对应关系如下
	角色名	文件夹名
	芙宁娜	fufu
	胡桃		hutao
	空		kong
	纳西妲	naxida
	枫原万叶	wanye
	荧		ying
	钟离		zhongli
	红绿灯	红绿灯
	机器人	机器人
规则：
1. 启动时显示角色子文件夹下action中的default中的图片；
2. 当模型思考时（包括多个子agent，只要有思考的agent）就显示think中的图片；
3. 当模型发生错误时（包括多个子agent，只要有发生错误的agent），显示error中图片的随机一个；
4. 当模型回答完问题后（全部子agent完成回答），显示complete中的图片随机一个；
5. 图片显示优先级：error>think>complete>default；
6. 右键角色给出切换角色按钮；
7. 聊天框样式保存在角色子文件夹下 聊天框 文件夹中，使用情况根据图片名选择；
8. 当模型完成工作或发生错误时（若存在多个子agent，则其中一个子agent完成工作或发生错误），用指定聊天框并附带简短语言提示用户。普通 dsh web 附带“查看详细”，基于 1.0.37 跳转行为，并在用户从后台手动返回弹窗目标会话时主动关闭聊天框；DSH Desktop 的 `web`/`desktop` Profile 统一采用 Desktop 规则，用户手动返回弹窗目标会话时同样主动关闭聊天框。Desktop 中链接与聊天框必须同时出现和消失：原生通知开启时，仅当前台所在会话与通知会话不同时显示“跳转会话”并保留 600 秒，其他状态二者同时隐藏；原生通知关闭时，即使失焦、最小化或隐藏也恢复聊天框、“查看详细”、时长及已读行为；
